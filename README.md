## 🎤 Sobre mí

<div align="center">
  <a href="https://github.com/josevdr95new"><img src="https://avatars.githubusercontent.com/u/119988266?v=4" width="110" alt="Avatar de Josevdr95" /></a>
</div>

Hola, soy **Josevdr95** — builder desde Cuba 🇨🇺. Empecé forjando utilidades para Windows con VisualNeo Win (funciones, barras de proceso, salvapantallas, limpiadores de RAM) y hoy compilo **APKs Android escribiendo HTML, JS y CSS como si Java no existiera**, gracias a mi propio ecosistema [AppForge](https://github.com/josevdr95new/AppForge).

Me mueve construir herramientas que resuelven problemas **reales**: proxies que aguantan con la conexión que hay, tasas de cambio del BCC al día, bots que convierten lo que tú no quieres convertir a mano, y experimentos de agentes IA como [agent-browser-py](https://github.com/josevdr95new/agent-browser-py), que maneja un navegador con visión artificial.

> ⚡ **Filosofía del taller:** si la herramienta no existe, se construye. Si existe, se tunea. Y si al final suena bien… se sube el volumen. 🤘

- 📱 **Android sin sufrir Java** — el ecosistema **AppForge**: APKs nativas con HTML/JS/CSS vanilla + Capacitor, plantilla lista para producción y plugin para la tienda Apklis → [AppForge](https://github.com/josevdr95new/AppForge) · [appforge-template](https://github.com/josevdr95new/appforge-template) · [html2apk](https://github.com/josevdr95new/html2apk) · [capacitor-plugin-apklis](https://github.com/josevdr95new/capacitor-plugin-apklis)
